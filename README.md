# Запуск

Проект — React-приложение на Vite. Для запуска нужны Node.js 18 или новее и npm.

1. Откройте терминал в папке `lab2`.
2. Установите зависимости:

```bash
npm install
```

3. Запустите сервер разработки:

```bash
npm run dev
```

4. Откройте в браузере адрес `http://localhost:5173`.

Чтобы остановить сервер, нажмите `Ctrl+C` в терминале.
